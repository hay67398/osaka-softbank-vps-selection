## 线路方面，应该关注什么？

“软银线路”在实际使用中经常被说得过于简单。

官方当前对大阪 `JPOS_1` 的描述是 SoftBank peering，而不是对所有中国运营商、所有方向都承诺固定延迟或固定路由。访问效果可能因以下因素变化：

- 中国电信、中国联通、中国移动的出口不同
- 用户所在省份不同
- 去程和回程线路不同
- 高峰期国际出口拥塞
- 目标网站所在地区不同
- 服务器 IP 段本身的路由表现不同

所以，购买前最好先明确目标：

- 主要服务中国联通用户，重点测试联通线路。
- 主要服务中国电信用户，需要单独观察电信去回程。
- 面向日本本地用户，应测试中国方向以外的访问。
- 如果业务依赖固定低延迟，不能只凭“SoftBank”三个字做决定。

大阪软银的优势在于它有明确的软银网络互联，并且属于 BandwagonHost 的 E-Commerce 产品。官方页面同时列出了 Google、Cloudflare 和 NTT 等互联信息。

但这和大阪 CN2 GIA 的定位不同。CN2 GIA 页面直接强调 China Telecom CN2 GIA/CTG 等中国方向路由；如果你的业务几乎全部面向中国大陆，最好把两个产品放在一起比较，而不是默认软银一定全面优于 CN2 GIA。
